# InviCards Web

Beautiful digital invitations and personalized greetings, thoughtfully designed to make every celebration feel truly yours.

## Features

- **Elegant Aesthetics**: Carefully crafted typography, warm palettes, and responsive layouts.
- **Interactive Previews**: Showcase for wedding invitations, gender reveal cards, and thank-you cards.
- **Instant WhatsApp Integration**: Direct inquiry and ordering flow via WhatsApp.
- **Responsive Design**: Optimized for mobile, tablet, and desktop viewing.

## Live Demo & Usage

Open `index.html` (or `invicards_creative_homepage.html`) directly in any web browser, or host on GitHub Pages.
